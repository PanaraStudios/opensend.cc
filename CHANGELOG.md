# Changelog

## v2.0.0

WhatsApp, Messenger and Instagram join email. Adds WhatsApp Calling with IVR,
AI voice bots and browser agents, one Messages API, one Channels page,
channel-event automations, broadcasts across channels, Custom API key scopes,
and SDK and MCP coverage. Adds paged event catalogs, one-time IVR secrets and
rotation, optional browser TURN, safer webhook and broadcast processing, and
installer backups.

Anonymous usage statistics are **on by default**, including upgrades without a
saved preference. Turn them off in setup or instance settings, with
`--telemetry no` at install, or with the locked backend override
`OPENSEND_TELEMETRY=0`. See [the exact payload and controls](docs/telemetry.md).

See the [release notes](docs/releases/v2.0.0.md) and
[v1 → v2 upgrade guide](docs/upgrade-v1-to-v2.md) for changes requiring action,
security fixes and installation steps.
